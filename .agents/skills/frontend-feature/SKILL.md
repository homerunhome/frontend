# 기능 구현

1. 관련 페이지, 컴포넌트, API 모듈과 기존 구조를 확인합니다.
2. 변경 범위, 제외 범위, 영향받는 화면·상태·API를 정리해 공유하고 승인받습니다.
3. 기존 컴포넌트와 유틸리티를 먼저 확인하고 필요한 범위만 수정합니다.
4. API 연동이 있으면 명세에 맞는 타입과 오류 처리를 적용합니다.
5. 로딩·빈 결과·오류 상태, 반응형 동작과 기본 접근성을 확인합니다.
6. `npm run typecheck`를 실행하고, PR 전 `npm run build`를 실행합니다.

현재 프로젝트에 없는 테스트·린트·포맷 명령이나 패키지를 임의로 추가하지 않습니다.
