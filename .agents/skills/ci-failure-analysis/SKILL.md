# CI 실패 분석

1. 실패 로그에서 최초 실패 지점과 실행 명령을 찾습니다.
2. 타입 검사, Vite 빌드, 의존성 설치, 환경 설정 중 원인을 분류합니다.
3. 원인 파일과 재현 절차를 확인하고 최소 수정안을 제안합니다.
4. 검증을 약화하거나 실패를 숨기는 방식으로 우회하지 않습니다.
5. 수정한 뒤 실패한 명령과 관련 검증만 다시 실행합니다.
6. 최종 보고에 원인, 변경 내용, 실행 명령과 남은 환경 의존성을 기록합니다.
