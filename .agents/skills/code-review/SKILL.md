# 코드 리뷰

1. 승인된 변경 범위와 실제 diff가 일치하는지 확인합니다.
2. 기존 구조와 네이밍을 따르고 불필요한 추상화나 무관한 리팩터링이 없는지 봅니다.
3. 컴포넌트 책임, 데이터와 화면 상태 분리, 입력·오류 처리를 확인합니다.
4. 로딩·빈 결과·오류 상태, 반응형 동작과 접근성에 빠진 부분이 있는지 봅니다.
5. API 요청·응답과 민감정보 처리에 문제가 없는지 확인합니다.
6. 사용 가능한 검증 명령인 `npm run typecheck`와 `npm run build` 결과를 확인합니다.

발견 사항은 심각도 순서로 근거와 함께 정리하고, 근거 없는 스타일 선호는 지적하지 않습니다.
